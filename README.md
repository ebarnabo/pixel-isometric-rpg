# L'Éclat de la Persécution

Prototype de RPG isométrique pixel-art en pur HTML/Canvas.

## Comment jouer

- Ouvre `index.html` dans un navigateur (Chrome, Firefox, Edge...).
- **WASD** ou flèches : se déplacer
- **Clic** : attaquer l'ennemi le plus proche
- **E** : parler au forgeron (quand tu es près)
- **📦** : ouvrir / fermer le panneau d'équipement

## Histoire

Kael, jeune guerrier d'Aetherfall, est hanté par des visions de la dague maudite **Thief's Fang**.
Le forgeron Torin lui confie la quête de forger et manier **Persecution**, l'épée légendaire capable de sceller les ombres anciennes.

## Stack

- Canvas 2D + isométrie pure
- Particules & dégâts flottants
- UI overlay style dark/gold (inspirée des ARPG)
- Aucune dépendance externe
